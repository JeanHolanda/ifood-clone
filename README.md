# 🍔 iFood Clone

A front-end recreation of iFood's interface, created exclusively for educational and portfolio purposes.

🔗 **Live Demo:** https://jeanholanda.github.io/ifood-clone/

---

## About the project

This project is a responsive landing page inspired by iFood, developed to practice and improve my front-end development skills.

The interface was built from scratch using HTML, CSS and JavaScript, focusing on responsive layouts, reusable structures, user interaction and dynamic elements.

The project includes interactive restaurant and market carousels, navigation elements, a coupon popup and mouse-based dragging, adapting the experience to different screen sizes.

---

## Sobre o projeto

Este projeto é uma landing page responsiva inspirada no iFood, desenvolvida para praticar e aprimorar minhas habilidades em desenvolvimento Front-End.

A interface foi construída do zero utilizando HTML, CSS e JavaScript, com foco em responsividade, estruturas reutilizáveis, interação com o usuário e elementos dinâmicos.

O projeto conta com carrosséis interativos de restaurantes e mercados, elementos de navegação, popup de cupons e movimentação dos carrosséis através do mouse, adaptando a experiência para diferentes tamanhos de tela.

---

## 🎯 Purpose

The main goal of this project is to improve my Front-End development skills, especially:

- Building responsive interfaces
- Structuring layouts with HTML and CSS
- Working with Flexbox and responsive media queries
- Manipulating the DOM with JavaScript
- Handling user interactions and mouse events
- Creating interactive UI components

## ✨ Features

- 🍔 Restaurant cards carousel
- 🛒 Market cards carousel
- 🖱️ Mouse drag interaction for carousels
- ◀️▶️ Navigation buttons for carousels
- 🎯 Dynamic carousel positioning
- 🔒 Carousel movement limits
- 🎟️ Interactive coupon popup
- 📐 Responsive navigation and sections
- 🖼️ Responsive banners and images
- 🎨 Interface inspired by iFood's visual identity

---

## 💡 What I learned

- Building responsive layouts from scratch
- Using Flexbox to create flexible page structures
- Working with media queries for different screen sizes
- Understanding how `overflow` controls visible content
- Manipulating elements using `transform`
- Calculating carousel boundaries using element dimensions
- Handling mouse events such as `mousedown`, `mousemove` and `mouseup`
- Using `clientX` to track mouse movement
- Preventing the browser's default image drag behavior
- Creating reusable JavaScript logic for interactive components
- Controlling element states dynamically with JavaScript
- Improving user interaction through responsive UI behavior
